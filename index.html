How I work with AI

Where AI comes in, and where it doesn't

Lizzy Lee's was written entirely by hand. On the newer projects I work with AI coding agents (Claude Code, and Codex for the 3D work), and the further down the page you go, the more of the code is theirs. What stays mine on all of them is choosing the problem, writing the spec, and building the check that says whether it worked.

1. Spec first

Crosswordler's algorithm lives in a porting spec detailed enough to rebuild it in another language. Then it was rebuilt, in Dart, inside Word Wizard.

2. A gate for every phase

The TI-84 emulator had six phases. None started until the last one's test passed, beginning with 1.6 million single-instruction CPU tests.

3. Give the agent eyes

An agent that can't see the result guesses. So the emulator returns a JSON report and screenshots, and the phone apps get checked on an Android emulator, not just by unit tests.

4. Say what isn't done

The Bloodborne co-op work is unsolved, and its card says so. The airless basketball has never been printed, and its notes say that too.
